# scrcpy：安卓画面与摄像头预览

[English](README.md) | **简体中文**

本仓库基于 [Genymobile/scrcpy](https://github.com/Genymobile/scrcpy) 开发。scrcpy 可以通过 USB 或网络连接安卓设备，在电脑上显示设备画面；本分支还针对 Windows 摄像头预览增加了中文操作按钮。

> **注意**：本仓库是社区 Fork。上游官方发行版不包含本分支新增的中文摄像头工具栏。从上游下载的程序与本分支编译的程序功能可能不同。

## 摄像头预览功能

使用平板或手机摄像头作为视频源时，画面窗口提供以下按钮：

| 按钮 | 功能 |
| --- | --- |
| 切换摄像头 | 在前置和后置摄像头之间切换，画面会短暂重连 |
| 镜像 | 左右翻转预览画面，再次点击恢复；开启时按钮高亮 |
| 旋转 | 每次点击将预览画面旋转 90 度 |
| 全屏 | 进入或退出全屏，退出后恢复窗口大小和位置 |
| 截图 | 将当前预览画面保存为 BMP 文件，成功后显示保存位置 |

切换摄像头、镜像、旋转和截图时，程序会尽量保持视频窗口的大小和位置。画面比例变化时，窗口内可能出现黑边。截图包含当前的镜像和旋转效果，不包含工具栏；通常保存在 Windows 的“图片”文件夹中。

本功能用于在电脑窗口中**预览**摄像头画面，不会自动注册为 Windows 系统摄像头，因此不会直接出现在微信、会议软件或其他程序的摄像头列表中。

## 使用前准备

- 一台 Windows 64 位电脑。
- 一台带摄像头、运行 Android 12 或更高版本的安卓平板或手机。
- 一根支持**数据传输**的 USB 数据线。

scrcpy 的普通设备画面投屏支持更早的安卓版本；Android 12 是上述摄像头预览功能的要求。更多信息见[上游摄像头说明](doc/camera.md)。

## 连接平板

1. 在平板的“设置 → 关于平板”中确认 Android 版本。
2. 开启“开发者选项”：通常需要在“关于平板”中连续点击版本号数次。设置位置因设备品牌和系统版本而异。
3. 在“开发者选项”中开启“USB 调试”。
4. 使用 USB 数据线连接平板和电脑，保持平板解锁。
5. 如果平板弹出“允许 USB 调试”提示，确认连接的是自己的电脑后点击“允许”。

USB 用途不需要选择“摄像头”。如果设备无法识别，可以尝试“文件传输”模式，或更换支持数据传输的数据线。具体连接方式参见[连接文档](doc/connection.md)。

## 在 Windows 上启动

### 使用完整程序包

如果你已取得本分支的 Windows 程序包：

1. 完整解压压缩包，打开解压后的文件夹。
2. 双击 **“虚拟摄像头.exe”**，等待预览画面出现。
3. 使用结束后，关闭画面窗口。

请保留文件夹中的所有文件；如需移动程序，请复制整个文件夹，不要只复制启动程序。换电脑后还需要在平板上允许该电脑的 USB 调试请求。

本仓库当前未发布上述双击启动程序的发行包；请使用已经取得的完整程序包，或按下方说明从源码构建。上游官方发行版不含本分支的中文工具栏。

### 从源码构建

Windows 构建依赖和步骤见[构建文档](doc/build.md#windows)。构建并准备好同版本的 scrcpy 服务端文件后，可从命令行启动摄像头预览：

```powershell
scrcpy --video-source=camera --no-audio
```

摄像头选择、分辨率和帧率等参数见[摄像头文档](doc/camera.md)。仓库中的构建文档介绍的是 scrcpy 客户端构建流程，不会自动生成上述中文双击启动器或完整运行包。

## 常见问题

**启动后没有画面？** 确认平板已解锁、USB 调试已开启并已授权电脑；检查数据线是否支持数据传输，再尝试重新连接。若同时连接多台安卓设备，可先只保留需要使用的一台。

**没有 USB 调试授权提示？** 保持平板解锁，重新插拔数据线；必要时尝试在 USB 用途中选择“文件传输”。不同厂商的设置和提示名称可能不同。

**无法切换摄像头？** 确认设备有可用的前置和后置摄像头，并检查是否有其他应用占用摄像头。切换依赖重新连接，会短暂中断画面。

**找不到截图？** 在 Windows 文件资源管理器中打开“图片”，查找以 `scrcpy-` 开头、以 `.bmp` 结尾的文件；截图成功后弹窗也会显示保存路径。

**能否在其他软件里选择它作为摄像头？** 当前 Windows 版本只提供预览窗口；若要输出为系统可识别的虚拟摄像头，还需要额外方案。[上游的 V4L2 摄像头输出](doc/v4l2.md)仅适用于 Linux。
